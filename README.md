## 📈 The 5-Stage Progression to Super Intelligence (SI)

AMIX follows a rigorous 5-stage sovereign roadmap:

1. **Stage 1 (Use):** Harness foundation open-weights (Qwen 2.5, Llama 3.3, DeepSeek) through the Unified Gateway.
2. **Stage 2 (Customize):** Inject Indic domain embeddings, RAG pipelines, and code-mixed Hinglish vernacular context.
3. **Stage 3 (Fine-Tune):** LoRA / QLoRA parameter-efficient adaptation on indigenous commerce, GST tax structures, UPI protocols, and legal frameworks.
4. **Stage 4 (Train):** Pre-train sovereign Small Language Models (AMIX-Lite 0.5B–3B) optimized for sub-50ms inference on budget mobile hardware.
5. **Stage 5 (Research & SI):** Native reasoning models (AMIX-Reason) and multi-agent consensus protocols progressing to collaborative Super Intelligence.

## ⚡ Quickstart

### Option A: Zero-Install Instant CLI (`npx`)

Run AMIX directly from any terminal with Node.js installed:

```bash
# Check architecture & fleet status
npx amix status

# Intelligently route a prompt with cost & Indic detection
npx amix route "Bhai, Express app me CORS error aa rha hai kya karu?"

# Execute an objective using all 12 autonomous agents
npx amix fleet "Build an offline-first Kirana ledger sync engine with voice input"

# Run the AMIX-Indic-Bench evaluation suite
npx amix bench
```

### Option B: Local Repository Setup

```bash
git clone https://github.com/1nsharma-labs/amix.git
cd amix

# Run full Node test suite
npm test

# Launch interactive Model Context Protocol (MCP) server
npm run mcp
```

### Option C: Python FastAPI Backend

```bash
pip install -e .
uvicorn amix.app:app --host 0.0.0.0 --port 8000 --reload
```

## 🔌 Model Context Protocol (MCP) Integration

Connect AMIX to **Cursor**, **Claude Desktop**, or **Antigravity**:

Add this to your `claude_desktop_config.json` or `cursor.json`:

```json
{
  "mcpServers": {
    "amix": {
      "command": "node",
      "args": ["/absolute/path/to/amix/core/src/mcp/server.js"]
    }
  }
}
```

Exposed MCP Tools:
- `amix_route`: Intelligently route queries with cost & complexity breakdown.
- `amix_fleet_execute`: Run all 12 autonomous agents on any engineering objective.
- `amix_indic_benchmark`: Execute the Indic language evaluation suite.
- `amix_system_status`: Inspect AMIX & SHUTTER architecture status.
